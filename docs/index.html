Face Sort Studio

Professional local photo organization. Sort galleries by face with high-performance deep learning models and a polished browser UI—all 100% offline.

Local Setup Hosting Notes

Important

GitHub Pages can host this overview site, but it cannot run the real sorter. The working app needs Python, Flask, SQLite, local file access, and model downloads.

What The App Does

Upload reference photos, provide a gallery, and let the backend detect faces, compare embeddings, and sort images into matched, partial, and unmatched folders.

Why Pages Still Helps

Pages is still useful for a public project page, documentation, screenshots, release notes, and sharing the repository with recruiters, teammates, or users.

Backend Flask + SQLAlchemy
Vision OpenCV YuNet + SFace
Updates Server-Sent Events
Output Sorted local folders

Run It Locally

  1. Install Python 3.11 or newer.
  2. Install dependencies with python -m pip install -r requirements.txt.
  3. Create the data folders or run scripts/setup.ps1.
  4. Start the app with python run.py or scripts/run.ps1.
  5. Open the URL printed by Flask.
